計測条件:

- 計測は `tests/perf/measure_m0.py` が実験ごとに子 process を起動して行う。子 process には `RLIMIT_CPU` 900 s と wall timeout 1,200 s を設定した。
- `RLIMIT_AS`（6 GiB）も設定を試みたが、macOS では 40 件すべてで適用されなかった（`setrlimit` が失敗）。**メモリの上限は OS で強制されていない**。代わりに入力の規模を生成器側で段階的に決め、各実験の peak を記録した。
- 時間は `time.perf_counter` で 5 回計測し、中央値と最大値を記録した。メモリは `tracemalloc` の peak を別の実行で計測した（`tracemalloc` は時間を約 2.8 倍にするため、時間の値には使わない）。
- 入力は `tests/perf/gen_inputs.py`（seed 固定）で生成した。YAML Template は 0.5 / 1 / 2 / 4.8 MiB に段階的に大きくした。
- alias の fan-out は、論理 node 数を閉形式で計算できる入力だけを使った。木として走査（比較）したのは、論理 node 数が候補上限（3,000,000）以下と事前に確認した入力に限る。
- 比較処理（構造検査・構造比較・照合）は repository 外の prototype（`$TMPDIR` 配下の `proto_delta.py`）で計測した。prototype は repository に含めない（R14 AC12）。
- ログと一時生成物は `$TMPDIR/v11-m0/` に置き、作業終了時に削除した。

### 5-1. 初回失敗の原因分類

| test | 失敗内容 | 分類 | 対応 |
| --- | --- | --- | --- |
| `test_readers_refuse_a_final_symlink`（2 件） | 期待 `PathContainmentError`、実際 `InputNotFoundError`（`os.open` の `O_NOFOLLOW` による `ELOOP`、errno 62） | **Test Bug**（contract の前提誤り。製品の挙動は安全側で、symlink は読まれない） | 実際の挙動（`input_not_found`、exit 3）を固定するよう test を修正し、再実行で PASS |
